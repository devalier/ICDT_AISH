Test suites

Every test, probe, threshold and pass/fail criterion lives in packs/ as YAML under version control. Nothing there is code. This pane renders the live files, so what you read is what the next run will execute.

How the Working Group edits these

  1. Change the YAML in packs/.
  2. Run python3 -m harness validate — it names the file, the path inside it and what is wrong.
  3. Bump the suite version. A major bump if the change affects comparability of scores.
  4. Add a changelog entry saying what changed and why.
  5. Open a pull request. Working Group review is the approval gate.

Language parity

EU-MMLU measures whether a model knows the same things in each EU language. Parity is each language's accuracy relative to the model's own accuracy in {{ reference }} on the identical item set. The binding metric for EUIBA purposes is the parity floor — the worst language — not mean accuracy.

Why parity and not accuracy

A model that is strong in English and weak in Lithuanian is not fit for institutional use, whatever its average. Averaging across languages hides exactly the failure that matters in a multilingual administration, so this pane never shows a single accuracy figure without the per-language table behind it.

The dataset is {{ suite.dataset.repo if suite.dataset else 'EC-DGT-AI/EU-MMLU' }}, consumed in its published schema. Translations are CC BY 4.0; the English source material stays under the original MMLU MIT licence. This is a public dataset, so contamination in a cloud model's training data is plausible and a high score should be read with that in mind.
